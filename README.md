# Bloom & Co. — Flower Shop Prototype

A frontend-only demonstration of a premium flower-shop ordering website.

**Demo Prototype — Products, branding, pricing, and business information are for demonstration purposes.**

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## What’s included

- Public shop: home, catalog, product pages, occasions, cart, checkout, orders, account
- Manual payment demo (GCash / Maya / Bank Transfer) with QR and screenshot upload
- Downloadable order summary (HTML receipt, not a tax invoice)
- Admin demo: dashboard, product management, order status

Everything is stored in the browser (`localStorage`). There is no backend, no live payments, and no customer database.
