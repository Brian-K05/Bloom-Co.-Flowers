# Owner Alignment Checklist

Use this in the next meeting with the flower shop owner before kickoff.  
**Goal:** Lock budget, POS definition, and whether Meta/AI is launch-critical.  
**Related proposal:** [flower-shop-pos-messenger-proposal.md](./flower-shop-pos-messenger-proposal.md)

## How to use

1. Walk through each question with the owner.  
2. Mark **Agreed** and write the owner’s answer.  
3. Do not start build until Section A is complete.  
4. Track A (Meta/AI) only proceeds if Section C is agreed.
